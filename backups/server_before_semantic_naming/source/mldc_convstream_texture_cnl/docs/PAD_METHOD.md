# 四层CLS的直接交叉注意力精炼

版本：`mldc_pad_multilevel_cls_20261029`。四层对应ViT主干第9–12层，每层仅一次交叉注意力，不是三层MHCA＋FFN。

## 每层计算

对l=9,10,11,12，从第l块输出取得原始CLS c_l和patch P_l。四个分支分别拥有Q_l、K_l、V_l、W_O_l；师生在同一个分支共享这些投影。

学生查询：Q_l(LN(c_l))。教师查询：Q_l(LN(v_y))。同一个v_y供四个分支读取。键和值：K_l(LN(P_l))、V_l(LN(P_l))。

每头注意力为softmax(QK^T/sqrt(d_h))，将该注意力加权当前图像的V并拼接各头。学生CLS更新为c'_l=c_l+W_O_l contextS_l。教师对应更新为cT'_l=c_l+W_O_l contextT_l。教师原型只参与Q，既不放进V，也没有原型查询到视觉输出的残差或FFN。

投影内部宽度256，8头；最终每层CLS仍为768维。W_O零初始化以保留原SSL基线起点。四个分支独立并行，c'_9不会回写第10块ViT的输入。

## 聚合和身份原型

沿用原MLDC的同一组可学习softmax权重，学生gS=sum_l w_l c'_l，教师gT=sum_l w_l cT'_l。最终共享BN768和L2得到zS、zT。原ID及Triplet在原有训练位置约束学生最终分支；CNL、学生原型CE使用同一个zS。教师原型CE在zT空间计算。

仅有一张500×768身份原型表。构建阶段使用zS，教师启用后使用最终聚合zT执行AMU，每个不同训练图像只贡献一次更新，不按四个分支分别写原型。AMU困难负例按原型间相似度选取，mu按正负原型与当前教师嵌入的相似度计算，gamma=0.05；同图重复增强先合并。

## 注意力约束

AS和AT均为B×4×8×128。每个层、每个头沿128位置计算KL(AT.detach() || AS)，再平均批次、四层和头。系数5作用于平均损失，不把四层之和再乘5。每层KL及熵记录到training.csv与日志。

KL直接作用于本层原始CLS查询及patch选择。身份目标通过更新后的CLS和MLDC训练四个输出投影。本版已取消融合后额外生成学生注意力的路径，因此不再要求KL直接以最终融合向量为查询。

前5轮构建原型，第6轮起启用有效教师；KL教师目标停止梯度，师生共享投影仍会通过学生KL、身份目标更新。原型表本身由无梯度AMU更新，且只在成功优化器更新后写回。

## 推理、接口和检查点

主干新增按层返回patch的接口，旧默认返回和return_final_patches接口保留。第9–12层patch直接来自对应块输出，不把P12复制四份。标准推理运行四个学生精炼分支后MLDC聚合，不读取身份原型。推理导出保留四个分支。

return_pad_details中的layers保留原始12层CLS；refined_layers给出更新后的CLS；patches是键为9–12的字典；student/teacher提供四层注意力。return_components用于评估时提供精炼后的CLS，因此诊断名称中的raw表示BN前，而不是未经过精炼。

本版需新训练，不支持将旧融合后蒸馏的检查点直接续训。当前源码目录保持不变；原运行进程继续旧结构，下一次启动才加载本版。没有自动停止旧训练或启动新训练。
