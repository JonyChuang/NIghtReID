# P12 原型注意力蒸馏：当前实现

目录沿用 `mldc_convstream_texture_cnl`，当前模型版本为 `mldc_pad_p12_amu_bn_20261029`。本次按用户要求对齐AMU、蒸馏权重与嵌入归一化。旧LN版PAD结果继续作为独立历史实验，不能直接当作本版检查点。

单次骨干前向同时返回12层原始CLS与最后Block输出的128个P12 token。后四层CLS经原MLDC得到768维g；P12经LayerNorm和线性映射得到128×256的F。学生初始查询由g投影获得，教师初始查询由训练身份原型投影获得。

头由3个独立参数的MHCA＋FFN层串联，每层8个头。教师和学生调用同一个头实例，在对应层共享参数；三层之间不共享参数。每层都读取同一个F，查询由上一层输出更新。按PAD原文公式（7）使用残差和post-LayerNorm。

共享嵌入按论文公式（8）使用FC＋BatchNorm1d，再L2归一化，输出256维eS/eT。共享嵌入BN在学生和有效教师前向时分别更新统计；最终768维检索BN与它分开，每批只由最终学生融合特征更新一次。学生输出经零初始化的768×256投影，与g相加得到f。原ID、Triplet训练f对应路径；CNL使用且更新归一化的BN(f)。推理使用保存的BN统计，保留学生头，不读取身份标签或原型。

原型按官方训练身份建立独立记忆，与逐图CNL记忆分开。前5轮先用学生建立原型；第6轮起，身份至少有2张不同训练图像写入过记忆时启用教师，改由教师提炼表示更新原型。这是保留的冷启动适配规则，论文没有规定这5轮。

默认原型更新采用论文公式（10）、（15）、（16）的AMU。对旧原型v_y，先按原型间相似度选出e*=argmax_(e≠y) v_e^T v_y，再计算mu=sigmoid((v_y^T z_y-v_e*^T z_y)/gamma)，最后v_y←normalize((1-mu)v_y+mu z_y)。mu是新表示的权重；它与CNL的旧记忆momentum含义不同。gamma=0.05使用论文PRW设置（1/gamma=20）；论文没有NightReID设置。

PK采样中同一图的重复增强先聚合成一个单位向量，不把不同图先平均成一个身份向量。不同图按稳定图像索引顺序逐一AMU更新，后一个读取已更新的原型表。全新身份直接初始化；尚无有效负原型时暂用固定新表示权重0.5。原型与CNL仅在成功优化器步骤后写回，模型前向不写记忆。日志增加mu均值/最小/最大、更新样本数与蒸馏实际权重。

辅助身份目标对学生eS和有效教师eT分别计算原型交叉熵，有教师时平均两项。仅KL的教师注意力目标停止梯度；教师查询投影仍通过教师身份目标学习。这是实现中明确的监督选择，避免教师FC投影没有梯度。

注意力损失在每个图像、每层、每头内沿128个位置计算KL，再平均图像／层／头；不是先平均注意力图。概率及KL用FP32计算。默认注意力系数为论文的5；教师启用后直接使用5，不再做10轮线性增加。原型身份系数仍为1。

KL(A_t.detach() || A_s)仅切断KL从A_t回到教师查询、教师路径共享层及其图像特征的反向路径；学生路径对共享层、学生查询、图像骨干的梯度保留。教师身份CE仍能训练教师查询与共享层，原型表仍由无梯度AMU写回。共享参数可能经学生梯度或教师CE改变，因此detach不是冻结整个教师网络。论文未明确提供该停止梯度规则，本版保留已有选择。

总目标：原ID＋Triplet＋0.1 CNL＋原型身份项＋逐层逐头注意力KL。原Stem、ViT、MLDC、原损失、PK采样、数据增强、seed1234、120轮和20轮学习率预热继续沿用；新增头学习率为基础组的5倍，保留原参数组偏置倍率与余弦调度。

四个配置依次隔离新增头、原型提炼和KL：baseline_nightreid.yml、pad_head_only_nightreid.yml、pad_prototype_no_distill_nightreid.yml、pad_p12_nightreid.yml。输出目录带amu_bn标识，避免覆盖原实验。当前只实现单原型，没有多部位分离损失。本次没有更改MLDC查询、外层残差融合、辅助教师CE、OIM替代项等其他适配；整体仍不是原文完整复现。

完整检查点保存模型、CNL记忆、原型记忆、优化器和调度器状态。当前训练入口仍不提供自动resume，以免将旧ConvStream状态误加载到新结构。推理导出移除训练记忆与优化器状态，保留学生头参数。
