# CNL独立预热30轮

当前实验副本原地增加CNL预热，对照目的为检验早期伪正邻居约束的影响。只改变CNL启用时间，保留当前融合确认、三层支持、不确定集排除方案及可学习MLDC。

| 训练轮次 | 损失 |
|---|---|
| 第1–30轮，含第30轮 | 原ID＋原Triplet |
| 第31–120轮 | 原ID＋原Triplet＋0.1×CNL |

第31轮直接使用0.1，不做渐增。CNL的独立预热与原学习率预热分开：原`WARMUP_EPOCHS=20`、学习率调度和120轮总训练长度保持原设置。

## 配置、起点与输出

默认配置为`configs/night600_shared_cnl_consensus_warmup30.yml`，新增参数：

```yaml
SOLVER:
  CNL_WEIGHT: 0.1
  CNL_WARMUP_EPOCHS: 30
```

默认输出：

```text
./output/mldc_information_preservation/deep4_uniform_cnl_fused09_support3_uncertain08_warmup30_120
```

原服务器工程根目录中，下一次手动启动使用：

```bash
python mldc_information_preservation/train.py --config_file mldc_information_preservation/configs/night600_shared_cnl_consensus_warmup30.yml
```

本地独立副本的包装入口仍为`python train.py`。新对照从原SSL初始化开始完整训练120轮，不从当前已训练60轮的模型接着切换；旧结果不覆盖。当前训练进程已经加载旧实现，源码更新不会切换其设置。本次代码修改不启动、停止或重启训练。

## 预热期间的记忆

配置CNL权重仍为0.1，因此共享记忆始终建立。预热期间仍提取相同的四层参考键及最终融合键，在优化器成功更新后同步动量更新；首次直接写入，重复图像合并，AMP跳步不更新。第31轮直接使用预热过程中累积的记忆，不清空、不重新初始化。

预热期不执行邻居筛选或CNL损失，不引入CNL梯度。原ID／Triplet训练骨干、融合权重和分类头。此后CNL仍对比最终768维BN后L2描述子，通过当前查询更新骨干、融合logit和BN；候选键与筛选路径停止梯度。

正例规则仍为融合空间0.9相对门槛与至少三层各自0.9相对门槛共同成立。任一层或融合空间通过0.80相对门槛、但未成为正例的候选，作为不确定集排除出分母。CNL不读取真实身份标签，原主损失仍有监督。完整筛选定义见`FUSED_CONSENSUS_CNL_20261022.md`。

## 日志与历史兼容

`training.csv`增加：

- `cnl_effective_weight`：第1–30轮为0，第31轮起为0.1。
- `cnl_weighted`：实际加入总损失的CNL数值。
- `cnl_warmup`：是否处于预热轮次，1为是，0为否。

预热期间`cnl`、邻居数和有效查询比例等筛选统计为0占位，表示未计算，不表示已经测得没有正邻居；`cnl_memory_coverage`仍正常反映记忆填充。

元数据和检查点记录预热长度、预热后的固定权重、保存轮次的实际权重和预热期间记忆更新策略。历史配置默认`CNL_WARMUP_EPOCHS=0`，显式选择旧配置仍从第1轮按原权重启用CNL。

## 验证

```bash
python -m mldc_information_preservation.verify_cnl_warmup --full-model --report verification_shared_cnl_warmup30.json
```

验证30／31轮边界、预热期没有CNL调用且主损失梯度不变、启用后梯度精确为原损失加0.1倍CNL、预热记忆可供启用时查询、检查点记录及历史配置兼容。完整ViT测试只做合成数据前后向，无优化器更新或真实训练。
