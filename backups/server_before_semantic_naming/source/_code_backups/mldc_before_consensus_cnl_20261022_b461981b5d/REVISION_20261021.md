# BN参考空间与比例保持修订

只调整参考空间和保持目标。总目标仍为ID + Triplet + 0.1 × 保持损失，未启动本版本训练。
后四层仍为均匀初始化的可学习融合，不改为固定等权。

## 参考空间

融合BN在每次训练前向只调用一次。用BN输入的当前batch均值、biased方差以及相同BN仿射参数，
对CLS9–12分别施加同一变换并L2归一化；这些参考向量停止梯度。
不增加参数，不为四层建立独立BN，不重复更新running_mean、running_var或num_batches_tracked。
同次前向的归一化变换得到统一，跨batch记忆仍然保留原有的历史时滞。

## 损失

同身份不同原图为正例，摄像头不限；原图自身及重复增强不作为正对。
异身份负例仍取融合及四层各top-5的并集。

```text
d_l = cos(reference_l(q), reference_l(p)) - cos(reference_l(q), reference_l(n))
d_best = max_l(d_l)
可靠条件：d_best > 0.05
t = stop_gradient(0.8 × d_best)
d_f = cos(fused(q), fused(p)) - cos(fused(q), fused(n))
loss = max(0, t - d_f)
```

没有固定0.2上限。仍对每个查询的全部可靠组合取平均（包含已满足的零值），
再对有可靠组合的查询取平均；没有可靠组合则返回可反传零值。
这些采样及归一化方式保持原状，以免同时引入太多变量。

`PRESERVE_TARGET_MODE=capped`、`PRESERVE_REFERENCE_SPACE=raw_cls`可复现原始目标，
旧配置night600.yml已显式写入这两项。模型推理参数格式保持兼容，但旧raw_cls记忆不能用于新shared_bn训练。

## 运行

在服务器工程根目录执行：

```bash
/root/miniconda3/envs/QREID/bin/python mldc_information_preservation/train.py
```

默认使用configs/night600_bn_ratio.yml，结果目录：
`./output/mldc_information_preservation/deep4_uniform_bn_ratio08_preserve01_120`。

可分别做单因素对照（需新输出目录）：

```bash
# 只统一BN参考，保持旧0.2截断目标
python mldc_information_preservation/train.py SOLVER.PRESERVE_TARGET_MODE capped OUTPUT_DIR ./output/mldc_information_preservation/bn_capped_control
# 只使用比例目标，保留原始CLS参考
python mldc_information_preservation/train.py SOLVER.PRESERVE_REFERENCE_SPACE raw_cls OUTPUT_DIR ./output/mldc_information_preservation/raw_ratio_control
```
