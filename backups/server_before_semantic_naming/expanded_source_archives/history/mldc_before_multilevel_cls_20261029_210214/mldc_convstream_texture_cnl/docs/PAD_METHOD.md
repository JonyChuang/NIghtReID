# 唯一融合学生：当前实现说明

版本：`mldc_pad_fused_student_20261029`。

## 身份空间和注意力空间

全局特征g为原MLDC融合CLS9–12的768维输出。现有注意力头把P12映射到128×256，仅用于内部注意力运算。融合路径通过三层MHCA＋FFN得到最后查询qG，使用cG=qG/sqrt(256)控制残差输入的尺度，再经零初始化W（256→768）形成fS=g+WcG。内部状态没有身份分类、独立BN、身份原型或独立检索接口。

唯一学生身份表示为zS=normalize(BN768(fS))。最终BN输出的原classifier承担ID；原Triplet继续使用其原来位置的fS；CNL使用zS；学生原型CE也使用同一个zS。前BN/后BN是同一条身份分支的既有训练位置，不是两条学生身份分支。

## 最终融合特征的注意力

只有形成fS和zS后，才调用student_query(zS)。它与同一P12空间特征交互，经现有三层共享MHCA＋FFN得到AS。AS不是融合上下文注意力的重命名，也不对zS停止梯度。KL必须能回到实际zS和fS计算节点，以及生成融合特征的投影和骨干。

原型表改为768维z空间。prototype_query先归一化再投影至256维，生成AT和cT。教师的768维提炼特征定义为同一图像g+WcT，使用与学生同一个BN768和L2后得到zT。教师原型CE在这同一空间计算，教师有效时与学生原型CE平均。原型查询映射仍由教师CE学习；不复用ViT的Q/K/V参数或原生注意力。

三个深度位置的层参数不同；每一层被融合上下文、学生注意力读出、原型教师共同调用。融合计算先于学生注意力，因此没有用“尚未生成的融合特征”递归计算自身的循环。

## 损失与原型

总目标：原ID＋Triplet＋0.1 CNL＋原型身份CE＋5 KL。教师启用前只有学生原型CE；有效教师出现后，两项原型CE平均。KL沿每个空间分布计算，再平均图像、层、头。

KL目标AT.detach()仅阻断教师注意力路径的KL梯度。学生查询、共享层、最终融合特征和其上游保持可微。教师CE仍能更新教师查询和共享层。

原型构建前5轮使用zS；第6轮起，对至少两张不同训练图像构建过的身份，使用zT做AMU。困难负例按旧原型间相似度选取；gamma=0.05；mu为新表示权重。保持逐图更新、重复增强合并和成功优化器步骤后写回。CNL维持自己的768维逐图记忆，与身份原型表分开。

## BN和推理

旧256维FC＋BN身份嵌入已移除。师生共享最终BN768，训练时有教师则分别更新一次该BN统计。推理使用保存统计，且只运行生成fS的上下文路径。学生注意力读出只用于训练/诊断，不生成第二个检索向量。推理导出保留产生融合特征所需的头，不带原型和优化器。

当前结构需要新训练，不能续用旧双身份空间检查点。此次代码修改不提供新性能结论，亦未启动训练。
