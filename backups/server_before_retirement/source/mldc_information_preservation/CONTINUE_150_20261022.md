# 从120轮追加训练至150轮

本次延长对象为预热30轮CNL实验的最终`transformer_120.pth`，不选择历史最佳轮次替代120轮。

- 恢复模型全部参数、BN缓冲区、可学习融合权重，以及四层参考键和最终融合键的完整记忆。
- 追加第121–150轮；原CNL预热不重复，ID／Triplet与0.1×CNL继续工作，邻居规则保持原配置。
- 根据用户确认，全部参数组保持第120轮余弦调度结束时的学习率`8e-7`，不重新升高或衰减，不重启学习率预热。原调度终点的头部学习率下限也为此值。
- 旧120轮检查点没有优化器、AMP和随机数状态。本次重新初始化优化器动量、AMP缩放器及随机数种子，因此是模型与记忆的继续优化，不是逐步精确恢复原进程。
- 新检查点会额外保存优化器、调度器和AMP状态；仍不宣称能够逐位重放采样和所有随机过程。

原服务器工程根目录启动命令：

```bash
python -m mldc_information_preservation.extend_training \
  --checkpoint output/mldc_information_preservation/deep4_uniform_cnl_fused09_support3_uncertain08_warmup30_120/transformer_120.pth \
  --extra_epochs 30 --learning_rate 0.0000008
```

默认新目录为原目录名称加`_extend150`，旧模型、日志、结果不覆盖。新日志从121轮开始，初始融合权重记录为120轮；130、140、150轮检索评估，最终保存`transformer_150.pth`。若追加阶段超过起始120轮的mAP，则另外保存`transformer_best.pth`。

加`--verify_only`可以在CPU验证模型、配置、图像索引及记忆恢复，不创建结果目录、不启动训练。CPU单元检查：

```bash
python -m mldc_information_preservation.verify_continuation
```

续训元数据会记录来源检查点、追加轮次、固定学习率、记忆覆盖率、优化器是否恢复等实际状态。固定末轮低学习率产生的更新较小，追加30轮的结果用于观察该学习率下延长训练的影响。
