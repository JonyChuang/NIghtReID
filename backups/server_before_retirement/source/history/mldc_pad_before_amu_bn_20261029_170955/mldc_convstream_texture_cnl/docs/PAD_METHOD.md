# P12 原型注意力蒸馏：当前实现

目录沿用 `mldc_convstream_texture_cnl`，当前模型版本为 `mldc_pad_p12_20261029`。旧ConvStream教师不再构造或加载。

单次骨干前向同时返回12层原始CLS与最后Block输出的128个P12 token。后四层CLS经原MLDC得到768维g；P12经LayerNorm和线性映射得到128×256的F。学生初始查询由g投影获得，教师初始查询由训练身份原型投影获得。

头由3个独立参数的MHCA＋FFN层串联，每层8个头。教师和学生调用同一个头实例，在对应层共享参数；三层之间不共享参数。每层都读取同一个F，查询由上一层输出更新。按PAD原文公式（7）使用残差和post-LayerNorm。

共享嵌入投影输出256维单位向量eS/eT。辅助嵌入使用LayerNorm，使教师路径不额外更新原检索BN。学生输出经零初始化的768×256投影，与g相加得到f。原ID、Triplet训练f对应路径；CNL使用且更新归一化的BN(f)。推理保留学生头，不读取身份标签或原型。

原型按官方训练身份建立独立记忆，与逐图CNL记忆分开。先用学生表示建立原型，前5轮只做学生身份监督；第6轮起，身份至少有2张不同训练图像写入过记忆时，才启用该身份教师。原型读取发生在当前写回之前，教师表示在优化器成功更新后进行EMA写回。PK采样中同一张图的多次增强先合并，不计作多个独立支持图。当前EMA旧原型权重为0.5，不启用额外AMU或跨相机原型筛选。

辅助身份目标对学生eS和有效教师eT分别计算原型交叉熵，有教师时平均两项。仅KL的教师注意力目标停止梯度；教师查询投影仍通过教师身份目标学习。这是实现中明确的监督选择，避免教师FC投影没有梯度。

注意力损失在每个图像、每层、每头内沿128个位置计算KL，再平均图像／层／头；不是先平均注意力图。概率及KL用FP32计算。默认注意力系数1，原型身份系数1，注意力项从第6轮起在10轮内线性增加。这些新增系数是待实验验证的起点，不是PAD原论文最优值在NightReID的复现结论。

总目标：原ID＋Triplet＋0.1 CNL＋原型身份项＋逐层逐头注意力KL。原Stem、ViT、MLDC、原损失、PK采样、数据增强、seed1234、120轮和20轮学习率预热继续沿用；新增头学习率为基础组的5倍，保留原参数组偏置倍率与余弦调度。

四个配置依次隔离新增头、原型提炼和KL：baseline_nightreid.yml、pad_head_only_nightreid.yml、pad_prototype_no_distill_nightreid.yml、pad_p12_nightreid.yml。当前只实现单原型，没有把未验证的多部位分离损失混入本轮。

完整检查点保存模型、CNL记忆、原型记忆、优化器和调度器状态。当前训练入口仍不提供自动resume，以免将旧ConvStream状态误加载到新结构。推理导出移除训练记忆与优化器状态，保留学生头参数。
